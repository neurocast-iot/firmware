# OSD 水印配置对外协议文档（服务器/云端接入用）

本文档定义云端/服务器下发到设备的 `osd` 段 JSON 格式（对外协议）。
设备端负责全部像素换算、钳位、图片下载等设备内部实现，**服务器不需要计算任何像素值，
也不需要感知设备文件系统**；设备内部字段（如字库路径）不在本协议内下发。

## 一、总体结构

```json
{
    "osd": {
        "enabled": true,
        "elements": [ ... ]
    }
}
```

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `enabled` | bool | `true` | OSD 总开关。关闭后画面上没有任何水印 |
| `elements` | array | 空 | 水印元素列表，**数组顺序即显示顺序**，见下文 |

> 设备内部还有一个 `font_file` 字段（点阵字库文件路径），属于固件实现细节，
> **不在对外协议内，云端不要下发**。注意：当前固件解析层对云端来源的该字段没有屏蔽，
> 误发错误路径会导致所有文字类水印画不出来，协议约定以本文档为准——不下发；
> 后续固件版本会加白名单屏蔽，在那之前靠约定保护。

每个元素是一个对象，所有元素共用一组键，每种类型只取自己用得到的键，多余键会被忽略。

## 二、通用约定

### 1. 千分比坐标

位置、尺寸类字段（`x` `y` `w` `h` `r` 以及多边形的顶点）全部用**千分比**：
`0~1000` 的整数，表示占画面宽度/高度的比例。

- `x = 12` 表示距画面左边缘 1.2% 宽度的位置
- `y = 500` 表示画面垂直居中
- 越界值不会报错，设备会自动钳到 `0~1000` 边界继续显示

同一份配置在不同分辨率（主通道 1920x1080、子通道 640x480）下保持相同的相对位置，
这是前端不需要算像素的原因。

### 2. 每个元素同时显示在两个画面上

每个元素会同时渲染到主通道（高清）和子通道（预览小流），前端只配一份。

### 3. 槽位上限：每路画面最多 4 个元素

当前芯片每路画面只有 4 个叠加区域：

- 按 `elements` 数组顺序从前到后占位
- `enabled: false` 的元素、内容为空的标签**不占位**，不会挤掉后面的元素
- 超出 4 个的部分直接丢弃（设备日志会告警），**前端应限制可添加的元素数量**

## 三、公共字段

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| `id` | string | 是 | - | 元素唯一标识，前端生成，用于管理（增删改定位） |
| `type` | string | 是 | - | 元素类型，见下表；未知类型会被设备剔除 |
| `enabled` | bool | 否 | `true` | 单元素开关 |
| `x` | int | 是 | `0` | 千分比横坐标。文本/矩形/位图=左上角；圆/椭圆=圆心 |
| `y` | int | 是 | `0` | 千分比纵坐标，语义同 `x` |
| `opacity` | int | 否 | 见说明 | 透明度 `0~100`，0=完全不透明，值越大越透明。不填时矩形/多边形默认 `20`，其余默认 `0`。**注意：当前固件暂不支持透明度，参数会被保留但不生效，将来固件支持后自动生效，前端可以先做界面** |

### 支持的元素类型

| `type` | 说明 |
|---|---|
| `time` | 时间水印（自动刷新当前时间） |
| `label` | 固定文本水印（如设备名） |
| `rect` | 实心矩形（遮盖块） |
| `circle` | 实心圆 |
| `ellipse` | 实心椭圆 |
| `polygon` | 实心多边形（任意 3~16 个顶点） |
| `bitmap` | 位图（BMP 图片，如 logo）。**当前固件版本未生效**，协议先定义好，见 4.7 |

### 颜色取值（`color` 字段）

固定 6 种：`black` / `white` / `red` / `green` / `blue` / `yellow`。
其它取值自动回落为 `black`。

### 字号档位（`size` 字段）

固定 3 档：`small` / `medium` / `large`，其它取值自动回落为 `medium`。

实际字号（像素）由设备按**画面高度**换算，不是等比缩放：

```
原始值 = 画面高 × 档位千分比 / 1000    （small=30、medium=44、large=60）
字号   = floor((原始值 + 8) / 16) × 16，最小 16    （就近取 16 的整倍）
```

前端预览必须用同一个公式（尤其取整方向：向上取整在部分分辨率上字号会差一倍，
如 432 高、medium 档：就近取整=16，向上取整=32）。各档位在不同分辨率上的实际字号：

| 画面高 | small | medium | large |
|---|---|---|---|
| 432 | 16 | 16 | 32 |
| 480 | 16 | 16 | 32 |
| 720 | 16 | 32 | 48 |
| 960 | 32 | 48 | 64 |
| 1080 | 32 | 48 | 64 |

文字占宽 = 字数 × 字号 / 2（ASCII 算 1 字、中文算 2 字，勿用浏览器度量）；
贴右摆放时 `x = 画面宽 − 字宽 − 4`；字号与分辨率绑定，切换分辨率后贴边元素需重新算坐标。

## 四、各元素类型字段详解

### 1. time —— 时间水印

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| `size` | string | 否 | `medium` | 字号档位 |
| `format` | string | 否 | `YYYY-MM-DD` | 日期格式，仅三种合法值，其它回落默认 |
| `show_week` | bool | 否 | `false` | 日期后是否追加星期（如"周四"） |

`format` 取值与实际显示效果（时间部分 `HH:MM:SS` 始终显示）：

| 取值 | 显示示例 |
|---|---|
| `YYYY-MM-DD` | `2026-08-28 15:27:38` |
| `MM-DD-YYYY` | `08-28-2026 15:27:38` |
| `Chinese` | `2026年08月28日 15:27:38` |

```json
{
    "id": "time_main",
    "type": "time",
    "enabled": true,
    "x": 12,
    "y": 22,
    "size": "medium",
    "format": "YYYY-MM-DD",
    "show_week": false
}
```

### 2. label —— 固定文本水印

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| `text` | string | 是 | 空 | 显示内容；**空文本不会显示也不占槽位** |
| `size` | string | 否 | `medium` | 字号档位 |

```json
{
    "id": "label_main",
    "type": "label",
    "enabled": true,
    "text": "1号大棚",
    "x": 12,
    "y": 89,
    "size": "medium"
}
```

### 3. rect —— 实心矩形

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| `w` | int | 是 | `0` | 宽（千分比，占画面宽度） |
| `h` | int | 是 | `0` | 高（千分比，占画面高度） |
| `color` | string | 否 | `black` | 填充色 |

`x`/`y` 是矩形**左上角**。

```json
{
    "id": "cover_rect",
    "type": "rect",
    "enabled": true,
    "x": 300,
    "y": 350,
    "w": 250,
    "h": 200,
    "color": "red"
}
```

### 4. circle —— 实心圆

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| `r` | int | 是 | `0` | 半径（千分比，占画面**高度**） |
| `color` | string | 否 | `black` | 填充色 |

`x`/`y` 是**圆心**。

```json
{
    "id": "mark_circle",
    "type": "circle",
    "enabled": true,
    "x": 500,
    "y": 500,
    "r": 50,
    "color": "white"
}
```

### 5. ellipse —— 实心椭圆

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| `w` | int | 是 | `0` | 横向直径（千分比，占画面宽度） |
| `h` | int | 是 | `0` | 纵向直径（千分比，占画面高度） |
| `color` | string | 否 | `black` | 填充色 |

`x`/`y` 是**椭圆中心**。

```json
{
    "id": "mark_ellipse",
    "type": "ellipse",
    "enabled": true,
    "x": 500,
    "y": 500,
    "w": 200,
    "h": 100,
    "color": "blue"
}
```

### 6. polygon —— 实心多边形

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| `points` | array | 是 | - | 顶点列表，格式 `[[x, y], ...]`，每个坐标都是千分比；**至少 3 个点，最多 16 个**（超过自动截断），不足 3 个的元素会被剔除 |
| `color` | string | 否 | `black` | 填充色 |

多边形不需要 `x`/`y`/`w`/`h`，位置和大小完全由顶点决定。
首尾不需要重复闭合（设备自动闭合）。

```json
{
    "id": "warn_triangle",
    "type": "polygon",
    "enabled": true,
    "points": [[600, 650], [720, 880], [480, 880]],
    "color": "yellow"
}
```

### 7. bitmap —— 位图

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| `w` | int | 是 | `0` | 目标显示宽（千分比），图片缩放到该尺寸 |
| `h` | int | 是 | `0` | 目标显示高（千分比） |
| `image_url` | string | 是 | - | 图片下载地址（建议 HTTPS），由服务器管理；设备自行下载并缓存 |

> **当前固件版本不生效**：设备还没实现下载通道，位图元素会被忽略（不显示、不占槽位）。
> 协议先定义到位，服务器可以按此对接，设备实现下载后自动生效，协议不用再改。
>
> 将来的设备行为约定：收到配置后按 `image_url` 下载，存进设备内部缓存目录（服务器不感知路径），
> 同一 URL 已缓存则不重复下载；下载失败或格式错误时仅该元素不显示，其它元素不受影响。
>
> 图片格式要求（**服务器上传前必须校验**）：BMP、24 位色、无压缩，建议 ≤200KB；
> 设备按最近邻采样缩放到目标尺寸（可能轻微锯齿）。

`x`/`y` 是位图**左上角**。缺 `image_url` 或宽高为 0 的元素会被剔除。

```json
{
    "id": "logo_bitmap",
    "type": "bitmap",
    "enabled": true,
    "x": 820,
    "y": 40,
    "w": 80,
    "h": 80,
    "image_url": "https://cdn.example.com/osd/logo_1.bmp"
}
```

## 五、设备端的容错行为（前端可不重复校验，但建议校验）

| 情况 | 设备行为 |
|---|---|
| `x`/`y`/`w`/`h`/`r`/顶点坐标超出 `0~1000` | 钳到边界，元素照常显示 |
| `type` 不在 7 种之内 | 整个元素剔除 |
| `size` 不在三档之内 | 回落 `medium` |
| `format` 不在三种之内 | 回落 `YYYY-MM-DD` |
| `color` 不在六种之内 | 回落 `black` |
| `opacity` 超过 100 | 钳到 100 |
| 多边形顶点超过 16 个 | 截断保留前 16 个 |
| 多边形顶点不足 3 个 | 整个元素剔除 |
| 位图缺 `image_url` 或宽高为 0 | 整个元素剔除 |
| 元素总数超过 4 个有效元素 | 第 5 个起丢弃 |

## 七、服务器端注意事项

1. **只做千分比，不做像素**：所有坐标尺寸都是 `0~1000` 的比例值，管理界面预览时
   可按预览区尺寸自行换算显示，但下发值必须是千分比整数
2. **`id` 必须唯一**：同一份配置内不能重复，建议用 UUID 或递增编号
3. **有效元素数量限制 4 个**：`enabled: false` 的预留元素不限，但同时开启的（含有
   内容的标签）最多 4 个
4. **`elements` 是整体替换语义**：每次下发全量数组，设备端不做与旧配置的合并；
   下发空数组 = 清空全部水印，建议服务器侧对空数组做二次确认或告警（可选）
5. **透明度暂时不生效**：`opacity` 字段先做进界面没关系，参数链路已经打通，
   当前芯片固件不支持半透明混合，等固件支持后无需改配置格式自动生效
6. **位图当前版本不生效**：设备未实现下载通道，`bitmap` 元素会被忽略（不显示、不占槽位）；
   服务器可以按 `image_url` 协议先行对接，设备实现后自动生效，协议不变。
   图片由服务器统一校验格式（BMP、24 位、无压缩）后再提供下载，别把格式风险留给设备端运行时发现。
7. **不下发设备内部字段**：`font_file` 等固件实现细节字段不在本协议内，下发清单以本文档为准。
